# Preview MasterData

Screenshot desktop (1440 × 1050) dan ponsel (390 × 844) menggunakan data simulasi,
bukan konfigurasi MinIO produksi.

- `settings-desktop.png`, `settings-mobile.png`: identitas, logo/icon/favicon.
- `storage-desktop.png`, `storage-mobile.png`: konfigurasi MinIO.

Browser memeriksa submenu MasterData, penyimpanan dan pemuatan ulang branding,
judul browser/favicon/login, upload logo, kegagalan dan keberhasilan tes koneksi,
secret yang dikosongkan setelah tersimpan, pembatasan operator, dan overflow ponsel.

Migration database sudah dijalankan. Detail konfigurasi ada di
[docs/settings.md](../../docs/settings.md).
